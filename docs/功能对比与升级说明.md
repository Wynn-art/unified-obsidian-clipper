# 功能对比与升级说明

比较对象是用户提供的本地版本：Unified Obsidian Clipper 0.0.1、YouTube Digest 1.2.0、Bilibili Digest 0.4.3。未把 README 中的未来建议当作已实现功能，也未声称这些是网络上的最新版本。

结论：两个参考项目在视频学习细节上更完善，但不是整体比统一扩展更全。原扩展覆盖网页剪藏、高亮、阅读、Obsidian REST 写入和 Canvas；因此保留原功能，补充学习功能，不用独立版覆盖整个项目。

## 使用

1. 更新后在 Chrome 扩展管理页重新加载原来的 Unified Obsidian Clipper，然后刷新已打开的 YouTube/B站页面。不要把原扩展删除重装，否则可能丢失扩展内本地资料。
2. YouTube 页面打开侧栏，可直接使用搜索框；顶部「Original / 中文 / 双语」同时作用于字幕、概览和笔记。选中字幕可解释或记笔记。「保存到 Obsidian」保留原来的完整学习输出与 Canvas 流程。
3. B站页面点击扩展图标，原剪藏弹窗中新增「学习模式 · 双语字幕 / 概览 / 笔记 / 问答」。播放器旁也有学习入口。原「AI」按钮仍打开原对话侧栏。
4. 学习侧栏右上角「打开设置」进入新模块设置。选择服务商、模型并自行填写密钥；新学习模块不会自动复制旧模块密钥，以免误发给其他服务商。
5. 「AI 对话」切回原侧栏；原侧栏的「切换到学习模式」可返回。若正在生成内容，建议等任务结束后再切换；后台可能继续执行已发出的 AI 请求。
6. 「学习稿保存到 Obsidian」保存当前视频/分 P 的概览、金句、笔记和当前显示方式的字幕。它复用「B站剪藏设置」里的 REST 地址、密钥和目录，不额外调用 AI。同名文件先确认，字幕加载失败或仍在加载时禁止保存。原剪藏的 Canvas 输出仍使用原入口。
7. 学习模式设置页可导出/恢复 JSON 备份。新模块的学习笔记与原 AI 对话历史各自保存；也不会自动读取另一个独立扩展的数据，可使用其兼容备份导入。

## 数据与限制

- 没有删除或迁移原 YouTube/B站/网页设置、密钥、缓存和聊天历史；新增存储使用独立名称。
- YouTube 与公共学习输出仍使用原 DeepSeek 配置；此次没有把所有模块的 Provider 合并成一套。
- B站字幕继续依赖站点接口和登录/字幕可用性，YouTube 仍依赖 Supadata 原生字幕；没有新增音频转写或保证无字幕视频可用。
- 原扩展已有全站访问权限；本次只复用该权限并保留学习模块的可选服务商授权声明，没有安装其他扩展或读取实际密钥。
- 自动化与界面验证使用虚构数据，不代表真实站点、付费模型和 Obsidian 连通性已经实测。用户在原浏览器重新加载后还需按自己的配置实际试用。

## 开发检查

无需安装 npm 依赖。已有 Node.js 与 Python 3 时运行：

```sh
npm test
npm run check
npm run package
```

测试涵盖上游学习模块逻辑、IndexedDB/备份、字幕分块/引用、YouTube 翻译/搜索，以及新增的消息隔离、联合后台启动、侧栏切换、Obsidian 覆盖取消、视频切换期间禁止误存。打包排除 tests 和测试用虚构数据。
