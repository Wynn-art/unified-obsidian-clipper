# Unified Obsidian Clipper v0.5.8

这是从 GitHub 初始版本 `v0.0.1` 以来的首个完整功能发布。它把普通网页、YouTube 和 B站内容统一为一套面向 Obsidian 的中文学习工作流。

## 主要新增功能

- **统一剪藏入口**：保存网页文章、YouTube 视频和 B站视频，保留原有剪藏、高亮与阅读能力。
- **视频学习**：YouTube 支持字幕搜索、双语显示、选中文字记笔记和阅读位置恢复；B站支持字幕顺句、双语阅读、分块概览、引用问答与笔记整理。
- **中文学习资料**：生成中文总结、趋势、扩展知识和结构化笔记；英文专有名词与来源名称可保留。
- **思维脑图**：YouTube、B站和文章均随主笔记保存 Obsidian `.canvas` 文件。
- **成长对话**：围绕当前视频或文章连续提问，结合已完成问答与手动导入材料生成中文成长报告。
- **行动报告**：报告包含讨论目标与总结、具体启发、行动计划表格、复盘问题、完整问答和材料来源。
- **附件辅助分析**：可复制上下文到 Gemini 客户端，自行上传图片、文件、音频或视频，再将分析文字导回扩展继续提问；不需要 Gemini API。
- **统一设计**：所有主要界面采用相同的米白背景、白色卡片、陶土色按钮、圆角和个人 Logo。
- **文章长面板**：受 Chrome 工具栏弹窗 600px 上限影响，文章提供“打开全高对话面板”，在网页右侧显示接近全高且可调整尺寸的面板。

## Obsidian 保存规则

- 没有成功问答时：保存主笔记与思维脑图，不生成报告。
- 有成功问答时：额外保存同目录的 `原文件基础名 - 对话报告.md`，并在主笔记中加入链接。
- 报告生成失败时不开始新一轮文件写入；部分文件写入失败时，同一面板重试只补存缺失文件。
- YouTube 和 B站报告通过 Obsidian Local REST API 直接写入 Markdown。
- 普通文章报告通过严格百分号编码的 Obsidian URI 写入，空格使用 `%20`，保留中文、标题、列表和表格结构。

## 配置说明

- YouTube 与文章成长对话复用 YouTube 设置中的 DeepSeek 配置。
- B站学习模式使用独立的模型设置，Obsidian 保存位置沿用 B站剪藏设置。
- Gemini 客户端只用于用户主动上传附件的辅助分析，不替代扩展所配置的模型 API。
- 升级不会主动清空现有设置、对话记录或 Obsidian 文件。

## 安装

1. 下载 Release 附件 `unified-obsidian-clipper-0.5.8.zip`。
2. 解压后打开 `chrome://extensions`。
3. 启用“开发者模式”，选择“加载已解压的扩展程序”。
4. 如果覆盖旧版本，请重新加载扩展并刷新已经打开的网页。

## 已知限制

- Chrome 工具栏弹窗最高约 600px，长对话应使用网页内全高面板或侧栏。
- 普通文章的 Obsidian URI 表示保存请求已发出，扩展无法像 Local REST API 一样确认磁盘最终写入结果。
- 模型生成内容需要人工核实；附件分析结果来自用户手动导入的客户端文本。
