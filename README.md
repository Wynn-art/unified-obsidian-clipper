# Unified Obsidian Clipper

一个 Chrome 扩展，把 YouTube / Bilibili 视频和任意网页一键剪藏到 Obsidian：自动抓取视频字幕与信息、调用 AI 生成摘要和笔记、支持网页高亮和阅读模式。

当前稳定版本：**v0.5.9**。版本变化见 [CHANGELOG](CHANGELOG.md)，完整发布说明见 [v0.5.9 Release Notes](docs/releases/v0.5.9.md)。

### 安装

1. 从 GitHub Releases 下载 `unified-obsidian-clipper-0.5.9.zip` 并解压。
2. 打开 Chrome 的 `chrome://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的目录。
4. 更新版本后，请在扩展管理页点击“重新加载”，并刷新已打开的 YouTube、B站和文章页面。

点击按钮后，小弹窗关闭，并在当前网页右侧打开已有的内嵌剪藏面板。该面板默认使用网页可用高度减 24px，支持从左侧、底部和左下角拖动调整尺寸，并记住调整后的宽高；保存区仍在成长对话上方。此变化不新增权限，也不改变模型、报告或 Obsidian 保存逻辑。

## 0.5.0 文章成长对话与报告

文章剪藏弹窗和侧栏底部新增与 YouTube 相同的「成长对话」，基于当前提取的文章正文进行中文问答；使用 **YouTube 设置中的 DeepSeek 配置**，无需再配置 Gemini API。长对话建议在文章侧栏进行，避免弹窗因切换应用而关闭。

1. 打开文章剪藏面板，等待正文及模板字段加载完成，展开底部「成长对话」。提取范围沿用现有正文、选区与高亮规则；不会假设读到了未提取的原文或附件。
2. 输入自己的问题、目标或时间约束，点击「发送」。报告包含讨论总结、成长启发、下一步行动（产出、时间、验收标准、障碍与替代方案）、复盘问题和完整已完成问答。
3. 可以先点击「生成／预览成长报告」。保存到 Obsidian 时，有至少一组成功问答就一并保存笔记、`.canvas` 脑图和 `原文件基础名 - 对话报告.md`，主笔记包含报告链接；未预览也会自动生成。没有问答、只有草稿、失败请求或仅导入材料时，仍只保存笔记与脑图，不调用报告模型。
4. 图片、文件、音频、视频沿用客户端辅助流程：复制提示到自己的 Gemini 客户端，自行上传附件，再把分析文字导入扩展继续提问。扩展不会读取原始附件；导入的文字会发送给已配置的模型，请先移除敏感信息。

对话按完整文章 URL（含查询参数和片段路由）独立保存在浏览器本地，与 YouTube、B站隔离。不同 URL 不会自动合并记录。刷新或切换文章时会取消旧任务，等待新正文和字段加载完成后才允许保存，迟到结果不会混入新文章。清空本地对话不删除已存入 Obsidian 的报告。

文章的追加、前置及日记模式可让多篇文章共用一份笔记：各篇报告文件名附带来源 URL 的摘要标识，避免相互覆盖。正文、报告或目标未变化时，部分文件失败后在当前面板内重试只补存缺失文件；报告生成失败则不会开始写入。报告随正文或对话变化重新生成，模型用量沿用现有计费。

普通文章保存仍使用 Obsidian URI，提示表示请求已发出，不能确认磁盘已经写入；请保持 Obsidian 可用并检查实际文件。日记模式使用现有 Local REST API。已经发出的写入无法撤销，同名覆盖前请备份手动修改的内容。资料上限与视频成长对话一致（40 组问答、10 份材料，上下文 300,000 字符），超限提示而不静默截断。

本版验证使用模拟模型与保存接口，不访问真实付费模型、不修改真实知识库。保留个人 Logo 和现有配置，无新增依赖。升级后重新加载扩展并刷新文章页面即可看到入口。

## 0.4.0 统一界面与思维脑图

YouTube、B站剪藏、B站学习、文章剪藏及设置、高亮、阅读入口的 13 个页面统一采用 YouTube 的米白背景、白色卡片、陶土色按钮和圆角。个人 Logo 保持不变。注入网页的控件样式仅作用于扩展自身，不改变原网页；阅读模式仍保留手动选择的阅读配色。

- **B站学习模式**：顶部「笔记与脑图保存到 Obsidian」同时保存 `.md` 学习稿和同名 `.canvas` 思维脑图。保留原学习稿、字幕和个人笔记，并补充中文总结、趋势与扩展知识。有成功完成的成长问答时，另存 `原文件基础名 - 对话报告.md`；无问答时不生成报告。旧版 B站剪藏入口已有的脑图保存继续保留。
- **文章剪藏**：保存正文与同名 `.canvas`，正文附带脑图链接。修正模板文件名已经带 `.md` 时产生 `.md.canvas` 的问题，并处理中文、空格及特殊字符的链接。
- **保存与重试**：B站学习模式在写入前统一检查笔记、脑图及报告是否已存在；部分文件写入失败，在当前面板内重试只补存缺失文件。内容或目标变更会重新保存。准备过程中可停止；切换视频、分 P 或超时会释放界面，丢弃迟到结果，避免继续保存旧内容。

B站学习稿和脑图使用「B站学习设置」的模型，保存位置沿用「B站剪藏设置」。文章与旧版 B站剪藏的学习资料生成沿用原有 YouTube/DeepSeek 配置；请先配置相应模型。生成资料和报告会产生正常模型用量。中文校验与 YouTube 共用，专有名词可保留原文。

文章普通保存沿用 Obsidian URI；扩展成功发出 URI 不等于已确认磁盘写入，请保持 Obsidian 可用并检查实际文件。日记保存沿用 Obsidian Local REST API，同一天保存多篇文章会更新同名日记脑图。已发出的模型请求可能在停止后继续处理，已发出的文件写入也无法撤回；同名覆盖前请备份手动编辑的内容。

验证包含 633 项自动化测试、13 个页面的配色检查及模拟接口下的两文件/三文件保存，未调用真实付费模型或写入真实知识库。升级后在浏览器扩展管理页重新加载扩展，再刷新 YouTube、B站及文章页面，无需删除重装。

## 0.3.0 B站成长对话与报告（历史版本）

B站**学习模式**底部新增与 YouTube 相同的「成长对话」，复用已验证的中文问答、报告和客户端材料导入流程。

1. 在 B站侧栏点击「切换到学习模式」（也可通过 B站视频的 Digest 入口进入），等待字幕加载完成。
2. 展开底部「成长对话」，结合当前视频提问。使用 **B站学习设置**中的模型；不会读取或改变 YouTube 的密钥配置。
3. 如需分析文件、图片、音频或视频，点击「复制给 Gemini 客户端」，自行上传附件；再将客户端分析文字导入。无需 Gemini API，扩展不会读取原始附件。导入文字会发送给所配置的 B站模型，请先移除敏感内容。
4. 点击顶部「学习稿保存到 Obsidian」：有成功完成的成长问答时，同时保存学习稿及 `原学习稿基础名 - 对话报告.md`，学习稿内包含报告链接。没有完成问答、只有草稿、失败请求或仅导入材料时，仍只保存学习稿，不调用报告模型。

报告包含目标总结、成长启发、具体行动计划（产出、时间、验收标准、障碍与替代方案）、复盘问题、完整已完成问答和材料来源。说明性内容要求简体中文，专名和原始问答保留原文。模型建议需结合实际判断。

记录、报告缓存、文件名和来源链接都按 **BV 编号 + 分 P** 区分，与 YouTube 记录隔离。停止或切换视频/分 P 后，未完成的回复不会回写，也不会继续发起旧报告保存；已发出的文件写入无法撤回。旧版「问答」标签和「AI 对话」保持原功能，不自动并入新的成长报告。

保存沿用 **B站剪藏设置**中的 Obsidian 地址、密钥和目录。若学习稿或报告已存在，写入前统一确认；报告写入失败后，在当前面板里重试只补存缺失文件，内容或目标变更则重新保存。无对话保存和清空本地记录都不会删除知识库内旧报告。同名覆盖会更新文件，请先备份手动编辑过的内容。

与 YouTube 相同，每视频分 P 最多40组问答、10份补充资料，单问题8,000字符、单资料20,000字符，请求上下文上限300,000字符。本地存储受浏览器配额约束。模型传输沿用 B站现有协议和有限回退，成长请求整体最多120秒；对话和新报告产生正常模型用量。无需新增权限、依赖或云服务，保留个人 Logo。

验证使用模拟模型与 Obsidian 接口，包括真实页面的无对话保存、问答、报告预览及双文件保存；未调用真实付费 API 或修改真实知识库。升级后重新加载扩展并刷新 B站页面即可使用。

## 0.2.0 YouTube 成长对话与报告

视频提取完成后，展开侧栏底部的「成长对话」。使用现有 YouTube DeepSeek 配置，结合视频字幕、概览、已完成问答与手动导入材料进行中文分析。支持停止请求、按视频恢复记录、预览报告和清空当前视频对话。

### 不需要 Gemini API 的附件流程

1. 输入问题，点击「复制给 Gemini 客户端」，复制内容包含视频背景、字幕与问题；此按钮不会自动发送内容。
2. 在你自己的 Gemini 客户端粘贴，并自行上传文件、图片、音频或视频（类型与大小以客户端实际支持为准）。
3. 将客户端分析文字粘贴到「导入客户端附件分析结果」，填写材料名称并导入，再继续向扩展提问。

扩展不直接读取或上传原始附件，也不自动操作 Gemini 客户端。导入的分析文字会作为后续 DeepSeek 请求的参考资料；请先移除不希望发送的敏感信息。Gemini 客户端账号不替代扩展使用的 DeepSeek API 配置。

### 报告与保存

- 有至少一组成功完成的问答：点击「保存到 Obsidian」时，一起保存笔记、脑图和同目录的 `原文件基础名 - 对话报告.md`，主笔记包含报告链接。
- 没有问答、只有草稿、失败请求或仅导入材料：仍只保存笔记与脑图，不调用报告模型。
- 报告包含目标总结、成长启发、行动计划（优先级、动作、产出、时间安排、验收标准、障碍与替代方案）、复盘问题，以及完整已完成问答和材料来源附录。说明性内容要求简体中文，原始对话及专有名词保留原文；模型输出仍需人工核实。
- 内容未变时复用已生成报告；某份文件写入失败时，同一面板内重试只写缺失文件。对话、资料或视频内容变化后重新生成报告。
- 清空只影响当前视频的扩展本地记录，不删除 Obsidian 中已有文件。再次保存同名文件会更新它，请先备份手动修改过的内容。

每视频最多40组问答、10份补充资料；单次问题最多8,000字符、单份资料最多20,000字符；请求上下文超过300,000字符时提示处理，不静默截断。记录保存在当前浏览器扩展本地存储中，受浏览器存储配额约束。文字问答和新报告会使用正常的 DeepSeek API 用量。

升级后在扩展管理页重新加载，再刷新 YouTube 视频页。保留原配置与个人 Logo，无新增权限或依赖。测试使用模拟模型和 Obsidian 接口，未调用真实付费 API 或写入真实知识库。

保留所有原剪藏功能，接入 YouTube Digest 1.2.0 的字幕搜索、笔记/概览双语、选中文字记笔记及阅读位置记忆；新增 B站学习模式（双语与顺句、分块概览、笔记编辑/备份、带原文引用的问答）。学习稿可直接保存到原 Obsidian REST 配置。

B站学习模式使用独立的模型配置，入口位于原剪藏弹窗与 AI 侧栏。升级后重新加载扩展并刷新视频页，无需删除重装。

完整功能对比、设置入口、验证范围与限制见 [功能对比与升级说明](docs/功能对比与升级说明.md)。

## 功能特性

- **YouTube 视频剪藏**：抓取视频字幕（transcript）、标题、作者等信息，写入 Obsidian 笔记
- **Bilibili 视频剪藏**：支持视频页与稍后再看列表，自动获取视频信息与字幕
- **网页剪藏**：任意网页正文提取，保存为 Markdown
- **AI 摘要与笔记**：内置 DeepSeek 等大模型接口（可自定义 Provider / Model），自动生成摘要、翻译、学习笔记
- **网页高亮**：在任意网页上划词高亮，随手保存
- **阅读模式**：沉浸式阅读页面
- **多语言界面**：内置 30+ 语言
- **快捷键**：
  - `⌘/Ctrl + Shift + O` 打开剪藏面板
  - `Alt + Shift + O` 快速剪藏
  - `Alt + Shift + H` 开关高亮
  - `Alt + Shift + R` 开关阅读模式

## 安装

1. 下载或克隆本仓库
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本项目文件夹

## 配置

### 1. Obsidian 本地接口

1. 在 Obsidian 社区插件市场安装并启用 **Local REST API with MCP**
2. 在插件设置中勾选 **Enable Non-encrypted (HTTP) Server**（地址通常为 `http://127.0.0.1:27123`）
3. 复制 API Key，填入本扩展设置页的「Local REST API 地址」和「Local REST API Key」

### 2. AI 接口（可选）

在扩展设置中添加 AI Provider（如 DeepSeek），填入 API Key，即可使用 AI 摘要与笔记功能。

### 3. 笔记目录

可配置自动写入的目录，支持变量：`{{created}}` / `{{upload_date}}` / `{{author}}` / `{{bvid}}`。
